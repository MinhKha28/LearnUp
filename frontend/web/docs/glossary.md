# Bảng thuật ngữ — LearnUP web

> Nguồn chuẩn cho mọi chữ hiển thị trong `src/locales/vi` và `src/locales/en`. Khi viết hoặc sửa bản dịch, dùng **đúng** thuật ngữ trong bảng, ở cả hai ngôn ngữ. Thuật ngữ mới phải được thêm vào đây trước, rồi mới dùng trong locales.

## 1. Vai trò

| English    | Tiếng Việt      | Key i18n                  |
| ---------- | --------------- | ------------------------- |
| Admin      | Quản trị viên   | `common:roles.admin`      |
| Organizer  | Quản lý tổ chức | `common:roles.organizer`  |
| Instructor | Giảng viên      | `common:roles.instructor` |
| Learner    | Học viên        | `common:roles.learner`    |
| Guest      | Khách           | `common:roles.guest`      |

## 2. Đối tượng nghiệp vụ

| English                            | Tiếng Việt                                  |
| ---------------------------------- | ------------------------------------------- |
| Organization                       | Tổ chức                                     |

| Course                             | Khóa học                                    |
| Module                             | Chương                                      |
| Lesson                             | Bài học                                     |
| Learning material (Video, Reading) | Học liệu (Video, Bài đọc)                   |
| Quiz                               | Bài kiểm tra                                |
| Assignment                         | Bài tập                                     |
| Assessment                         | Bài đánh giá (gọi chung Quiz và Assignment) |

## 3. Trạng thái

| English   | Tiếng Việt  |
| --------- | ----------- |
| Draft     | Bản nháp    |
| Submitted | Chờ duyệt   |
| Published | Đã xuất bản |
| Rejected  | Bị từ chối  |
| Locked    | Đã khóa     |

## 4. Lưu ý khi dùng

- **Assignment ≠ Assign.** "Assignment" luôn là _Bài tập_. Việc phân công khóa học cho học viên là _Phân công_; tiếng Anh viết "Course assignment(s)", không viết trơn "Assignments".
- **Assessment** là tên gọi chung khi không phân biệt Quiz hay Assignment. Khi biết rõ loại, dùng tên cụ thể (_Bài kiểm tra_ / _Bài tập_).
- **Peer Review**: danh từ và động từ đều quy về _chấm chéo_ ("Bài cần chấm chéo", "Chấm chéo bài của bạn").
- Viết hoa trong tiếng Việt: chỉ viết hoa chữ đầu câu/nhãn ("Quản lý tổ chức", không phải "Quản Lý Tổ Chức").
- Tên riêng sản phẩm giữ nguyên: **LearnUP**.
