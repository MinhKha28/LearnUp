# Demo Organizer UC24

## Điều kiện

- Dùng `develop` mới nhất, đã merge D71 chuẩn Title Case và có API trả `organizationTimezone`.
- Đăng nhập Organizer của tổ chức chứa dữ liệu demo. API đi qua gateway có danh tính hợp lệ.
- Các ca ghi dùng fixture của môi trường dev, chặn `NODE_ENV=production`, dọn đầu/cuối theo `organization_id` của fixture.
- Chưa hỗ trợ tìm Learner theo tên/email; bảng lấy 50 dòng/trang, giữ lựa chọn tối đa 500 người.

## Bật môi trường local trước khi bấm

Kịch bản cũ thiếu bước bật tenant-service thật. D46 chỉ bật PostgreSQL, course-service 8083, learning-service 8085 và frontend 3000; không bật tenant-service hay gateway. UC24 cần tenant-service 8084 cho danh sách Learner, lookup khi phân công và tên Instructor trong Course picker.

1. Giữ PostgreSQL của dự án đang chạy. Kiểm `docker port learnup-postgres`; máy kiểm chứng dùng `localhost:5433`. `tenant_db`, `course_db`, `learning_db` phải tồn tại. Không sửa cổng trong docker-compose để chạy demo.
2. Cấu hình `.env` local (không commit):
   - `services/course-service/.env` và `services/learning-service/.env`: `DATABASE_URL` trỏ đúng DB/cổng; `TENANT_SERVICE_URL=http://localhost:8084`; `INTERNAL_SERVICE_KEY` giống tenant và proxy frontend.
   - `services/course-service/.env` còn cần `LEARNING_SERVICE_URL=http://localhost:8085` để Course picker lấy số Learner theo Course.
   - `services/tenant-service/.env`: `NODE_ENV=development`, `PORT=8084`, `DATABASE_URL` của tenant_db, khóa nội bộ như trên, `FRONTEND_URL=http://localhost:3000`, `IDENTITY_SERVICE_URL=http://localhost:8081`, `NOTIFICATION_SERVICE_URL=http://localhost:8082`, `DEV_FAKE_AUTH=true`, `COURSE_CLIENT_MODE=http`, `COURSE_SERVICE_URL=http://localhost:8083`, `LEARNING_CLIENT_MODE=http`, `LEARNING_SERVICE_URL=http://localhost:8085`, `EMAIL_OTP_SECRET` ngẫu nhiên riêng cho local. Không cần Cloudinary cho kịch bản này.
   - `frontend/.env.development.local`: giữ các biến proxy D37; thêm đủ `VITE_TENANT_BACKEND_URL=http://localhost:8084`, `VITE_COURSE_BACKEND_URL=http://localhost:8083`, `VITE_ASSESSMENT_BACKEND_URL=http://localhost:8086`. URL assessment là cấu hình frontend bắt buộc; UC24 không gọi đánh giá thật.
3. Tại `services/tenant-service`, chạy `npx prisma migrate deploy`, `npm run build`, rồi bật tenant bằng lệnh dưới đây. Đợi log `Nest application successfully started`; lỗi thì dừng và báo log, không bỏ qua tenant.

```powershell
node -e "require('dotenv').config();process.env.NODE_PATH=require('node:path').resolve('dist');require('node:module').Module._initPaths();require('./dist/src/main.js')"
```

4. Tại root chạy `node scripts/inter1-demo.mjs --check`, rồi `node scripts/inter1-demo.mjs`. D46 tự migrate cả course/learning, chạy `course prisma:seed` (Title Case) và `learning db:seed`, reset/seed demo, rồi bật service. Không cần đặt biến tay: module path learning do D46 tính từ checkout; `ASSESSMENT_CLIENT_MODE=fake` và `ASSESSMENT_FAKE_RESULT_COURSE_IDS=0199a000-0000-7000-8000-0e0000000003` do D46 truyền cho learning-service và seed demo.
5. Dùng Organizer và Learner cùng tổ chức với Course Published. Các ID proxy Learner của D46 không tự tạo tài khoản tenant. Muốn kiểm chọn qua hai trang cần ít nhất 51 Learner fixture hợp lệ. Gateway/test harness chỉ được gắn danh tính và chuyển tiếp request tới service thật; không thay JSON Course, Learner hoặc kết quả phân công.
6. Sau lượt kiểm, dọn fixture đầu/cuối theo `organization_id`, tắt toàn bộ tiến trình D46 và tiến trình tenant riêng. Giữ PostgreSQL, không xóa volume.

## Kết quả đã chạy

Chrome headless 1440×1024, frontend thật và learning-service nguồn hiện tại trên Docker `node:22-alpine`, PostgreSQL 16. Fixture riêng gồm hai InProgress và một NotStarted quá hạn. Tenant/course không chạy trong lượt này nên chi tiết dùng fallback null đúng hợp đồng; múi giờ dùng tenant fake có sẵn của service.

Đạt các ca UI: kéo dài thành công; Miễn thành công; chặn gửi hai lần ở cả hai hộp thoại; lý do trắng bị chặn; Overdue chưa hoạt động không có nút Miễn; Miễn đồng thời trả 409 và tải lại. Network xác nhận sau mỗi 200 chỉ GET trang danh sách, dùng response cập nhật chi tiết. Fixture được dọn theo tổ chức sau lượt chạy.

## Kiểm chứng UC24.2 sau chuẩn hóa status và courseType

Ngày 17/10/2026: frontend, course-service và learning-service nguồn hiện tại chạy trên Docker Node 22, PostgreSQL 16. Migration đã áp dụng và seed mới đã chạy hai lần. `status` dùng Draft/Submitted/Published/Rejected/Archived/Disabled; `courseType` dùng Public/Private. Chữ hoa bị DTO trả 400.

Gateway localhost của lượt kiểm thử chỉ dựng danh tính và dữ liệu tenant (Instructor/Learner). Danh sách Course, lọc, I1/I2 và POST phân công đều đi qua service thật; không thay response Course hoặc response phân công. Lượt này chưa kiểm chứng tenant-service và gateway triển khai thật.

### Bước bấm đã chạy trên Chrome headless 1440×1024

1. Mở `/organizer/courses?status=Published`, chọn loại **Private**: API `GET /api/v1/courses/organization` gửi `status=Published&courseType=Private`, HTTP 200; hiện nhãn Published/Private tiếng Anh.
2. Mở `/instructor/courses`, chọn status **Draft**: API danh sách gửi `status=Draft`, HTTP 200; nhãn Draft giữ nguyên.
3. Mở `/organizer/assignments/assign` bằng Organizer của fixture ORG_TEST `0199a000-0000-7000-8000-0a00000000f2`. Danh sách chọn Course gọi API thật với `status=Published`, HTTP 200.
4. Chọn **Course Private kiểm thử tích hợp (không dùng cho demo)** (`0199a000-0000-7000-8000-0e00000000f2`, phiên bản 1); chọn Học viên kiểm thử (`0199a000-1710-7000-8000-0b00000000f1`), bấm **Phân công**.
5. POST thật trả HTTP **201**, `data={created:1,converted:0,completedOnAssign:0,restored:0}`; màn hình về `/organizer/assignments` và tải lại danh sách. I1 chấp nhận `Published/Private`.
6. Dọn fixture đầu/cuối theo ORG_TEST, gỡ khóa hai Course fixture. Sau lượt chạy không còn Enrollment của ORG_TEST. Các tiến trình ghi đều chặn `NODE_ENV=production`.

Test hồi quy bổ sung `services/course-service/test/course-values.learning-test.ts` đọc Private Course từ seed, gọi I1 thật, gọi API phân công thật, kiểm DB có Enrollment Required và dọn fixture. Chạy từ container learning-service với `TS_NODE_PROJECT=/app/services/learning-service/tsconfig.seed.json NODE_PATH=/app/services/learning-service node -r ts-node/register /app/services/course-service/test/course-values.learning-test.ts`.
